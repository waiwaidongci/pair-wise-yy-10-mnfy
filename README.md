# AeroStation 三维产品配置器

基于 Vue 3、TypeScript、Vite、Three.js、TresJS、Pinia、Tailwind CSS、Headless UI 和 Vue Router。

## 运行

```bash
corepack pnpm install
corepack pnpm dev
corepack pnpm build
```

## 已实现功能

- 由 Three.js 几何体程序化组成空气净化器模型，不依赖外部模型文件。
- 鼠标/触控拖拽旋转和缩放，移动端采用响应式布局。
- **整层整单方案**：一张单包含多个房间点位，每个点位填写面积与台数。
- 颜色、材质、续航与控制环**整单统一**；滤芯与支架**按点位各自选择**。
- **风量容量校验**：按滤芯单机覆盖上限（标准 45㎡ / 除醛 55㎡ / 医疗 65㎡）计算所需台数；新增点位若台数不足直接拒绝，并点名是哪个点位超限；已有点位容量不足实时红标列出。
- **材质联动**：材质改动后逐点位重算报价与规格，并自动修正不兼容选择（胡桃木降级医疗滤芯、非金属回退落地支架/长续航），修正按点位列出。
- 整单总价、各点位小计与关键规格随配置实时更新。
- 主视角、正视、俯视和细节四种相机预设，可在不同点位间切换预览。
- **分享链接**：新方案整体编码为 v2（全部点位 + 全局统一选项），打开后还原同样的点位、报价与修正；旧版 v1 单点位链接打开时自动升级为单点位整单方案，并应用兼容性修正。
